Three steps from download to full trainer control — usually under two minutes.

Grab the latest REANIMAL Trainer build from gitscore.cc, then extract the archive to any folder outside your game directory.

Questions

Frequently asked

Everything you need to know before running the REANIMAL Trainer.

Is the REANIMAL Trainer safe to run?

The trainer is fully open source — every build is compiled from the public repository, so you can audit the code yourself. It works as an external loader and does not modify or patch REANIMAL game files on disk.

Does it work with the Steam and Epic versions?

Yes. The loader attaches by process name, so it supports both the Steam and Epic Games builds of REANIMAL on Windows 10 and 11. Make sure the game is already running before you launch the trainer.
